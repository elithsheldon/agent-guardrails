# agent-guardrails

[English](README.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [한국어](README.ko.md) · [Français](README.fr.md) · [Español](README.es.md) · [Deutsch](README.de.md) · [Bahasa Indonesia](README.id.md) · [Bahasa Melayu](README.ms.md) · **ไทย**

ชุดฮุกกันพลาดสำหรับ Claude Code หยุดความผิดพลาดที่เกิดซ้ำ **ด้วยกลไก**
แทนที่จะเขียนบันทึกเตือนตัวเองเพิ่มอีกหนึ่งข้อ

> รับประกันด้วยกลไก ไม่ใช่ด้วยความใส่ใจของคน

## ทำไมถึงทำ

วัดจาก 30 เซสชัน รวมข้อความผู้ใช้ 887 ข้อความ พบว่าผู้ใช้ต้องแก้ผมทั้งหมด **44 ครั้ง**
และการแก้เหล่านั้นยุบรวมเหลือ 6 รูปแบบ ทุกรูปแบบถูกป้องกันด้วย
**ข้อความในไฟล์บันทึกเท่านั้น** บันทึกนั้นเขียนไว้แล้ว แต่ความผิดพลาดก็ยังเกิดอยู่ดี

| วัดได้ | รูปแบบ | การป้องกันปัจจุบัน |
| --- | --- | --- |
| 12 | คุณภาพการเขียน | `reply_check.py` ตรวจจับ |
| 9 | ประกาศว่าเสร็จเร็วเกินไป | `reply_check.py` ตรวจจับ |
| 9 | ส่งงานที่ไม่มีใครขอ | `outward_action_guard.py` **ปฏิเสธ** |
| 7 | บอกว่า "ทำไม่ได้" โดยยังไม่ได้ลอง | `reply_check.py` ตรวจจับ |
| 4 | อ่านคำสั่งตกหล่น | ไฟล์เกณฑ์ (ต่ำกว่าเกณฑ์ตัดสิน) |
| 3 | ผิดที่เก็บโค้ด/ผิดสภาพแวดล้อม | ไฟล์เกณฑ์ (ต่ำกว่าเกณฑ์ตัดสิน) |

กติกาการรับเข้า: **เกิด ≥5 ครั้ง = เกิดซ้ำ = บันทึกแก้ไม่ได้** เพราะบันทึกนั้นล้มเหลวมาแล้วหนึ่งครั้ง
ต่ำกว่า 5 ครั้งให้คงไว้เป็นข้อความ ถ้าทำเป็นด่านทั้งหมด คำเตือนจะล้นจนไม่มีใครอ่าน

## มีอะไรบ้าง

### ฮุก (ลงทะเบียนใน `~/.claude/settings.json` ทำงานทุกไดเรกทอรี)

| ไฟล์ | เหตุการณ์ | หน้าที่ |
| --- | --- | --- |
| `reply_check.py` | Stop | แจ้งเมื่อไม่มีบล็อกสถานะ, อ้างว่าเสร็จโดยไม่มีหลักฐาน, พูดว่า "ทำไม่ได้" ทั้งที่ยังไม่ลอง, สำนวนที่อ่านแล้วรู้ว่าเครื่องเขียน (คู่ตรงข้าม `X, not Y`, ขึ้นต้นด้วยการนับข้อ, ประโยคแยกส่วน, การเกริ่นนำเยิ่นเย้อ) และคำติดปากของแชตบอต **เตือนอย่างเดียว** เพราะการบล็อกที่ Stop เสี่ยงวนลูป |
| `outward_action_guard.py` | PreToolUse(Bash) | **ปฏิเสธ** การกระทำออกภายนอกที่ย้อนกลับยาก (PR/push/สร้างที่เก็บโค้ด/รีลีส/gist) และปฏิเสธ `<check> \| tail; echo $?` ด้วย เพราะนั่นคือรหัสออกของ `tail` ไม่ใช่ของตัวตรวจ |
| `guard_the_guards.py` | PreToolUse(Edit/Write) | ขอคำยืนยันก่อนแก้ตัวตรวจ ฮุก การตั้งค่า หรือหน่วยความจำ กันไม่ให้เอเจนต์ไปแก้ผู้ตัดสินแทนที่จะแก้ตัวงาน |
| `daily-retro-reminder.sh` | PostToolUse | เตือนให้ทำการทบทวนเมื่อเขียนรายงานประจำวัน |

### สกิล

`skills/daily-retro/` — วงจรปรับปรุงที่เริ่มจากการเขียนรายงานประจำวัน
ผลักความผิดพลาดแต่ละข้อลง **ให้ต่ำที่สุด** บนบันไดนี้:

> หน่วยความจำ → เอกสาร → สคริปต์ → การตรวจก่อนทำ → การทดสอบ → สิทธิ์

### สคริปต์

| ไฟล์ | จุดประสงค์ |
| --- | --- |
| `mistake-frequency.py` | **นับ** รูปแบบการถูกแก้จากทุกเซสชันที่ผ่านมา เพื่อให้ "อันนั้นแก้ไปแล้ว" เป็นตัวเลข ไม่ใช่ความรู้สึก |
| `verify-gates.py` | **การทดสอบตัวเองของด่าน** ป้อนทั้งข้อมูลที่ต้องทำให้ด่านทำงาน และข้อมูลที่ต้องไม่ทำให้ทำงาน |

### เอกสารอ้างอิง

`reference/anti-self-deception/` — กฎ 24 ข้อ สคริปต์ 15 ตัว และการตรวจประจำ 29 รายการ
จากระบบที่พัฒนามาแล้วของอีกทีมหนึ่ง นำมารวมโดยได้รับอนุญาตและผ่านการปกปิดข้อมูลระบุตัวตน
ดูรายละเอียดใน `ATTRIBUTION.md`

## สองตัวที่ได้ผลที่สุด

**`guard_the_guards.py`** การป้องกันอื่นทั้งหมดเฝ้าดูแต่ *ตัวงาน*
ไม่มีชั้นไหนกันไม่ให้ฝ่ายที่ถูกตรวจไปเขียนตัวผู้ตัดสินใหม่

**`verify-gates.py`** ผมเขียนตัวตรวจความล้าสมัยสามครั้ง และทั้งสามครั้งมันผ่านหมดทั้ง 18 รายการ
ถ้าไม่ได้อ่านตัวเลข ผมคงรายงานว่า "ปกติดี" ติดกันสามครั้ง
**การตรวจที่ไม่เคยล้มเหลวเลย อาจไม่ได้ปกป้องอะไรอยู่เลย**

## การติดตั้ง

โคลนแล้วรัน `bash install.sh` จะคัดลอกไปที่ `~/.claude/hooks/` และ `~/.claude/skills/`
พร้อมลงทะเบียนฮุกใน `~/.claude/settings.json` — เพิ่มเข้าไปเท่านั้น ค่าเดิมยังอยู่ครบ

อ่าน `CLAUDE.example.md` ปรับให้เข้ากับเครื่องของคุณ (พาธหน่วยความจำ ตำแหน่งรายงานประจำวัน)
แล้ววางไว้ที่ `~/.claude/CLAUDE.md`

จากนั้นให้รันการทดสอบตัวเองเสมอ:

    python3 ~/.claude/skills/daily-retro/scripts/verify-gates.py

ทดสอบผ่าน 21/21 บนเครื่องใหม่ และ 26/26 บนเครื่องที่ตั้งค่าแล้ว

## ข้อควรทราบ

- ฮุกอยู่ใน `~/.claude/` จึงมีผล **ในทุกไดเรกทอรี** แต่หน่วยความจำไม่เป็นเช่นนั้น
  เพราะแยกตามไดเรกทอรีที่เริ่มรัน Claude หลักการที่ใช้ข้ามโปรเจกต์จึงควรอยู่ใน
  `~/.claude/CLAUDE.md` ซึ่งถูกอ่านทุกเซสชัน
- `outward_action_guard.py` จะบล็อก push ถ้าตั้งใจจะ push ให้ใส่ `CLAUDE_OUTWARD_OK=1`
  ถ้ารบกวนเกินไปให้ลบรายการออกจาก `GUARDED`
- `reply_check.py` ใช้ regex จึงมีการแจ้งผิดพลาดบ้าง เมื่อเกิดขึ้นให้
  **จำกัดรูปแบบให้แคบลง อย่าลบการตรวจทิ้ง**
- ข้อความขณะทำงานของฮุกยังเป็นภาษาญี่ปุ่น ส่วนนั้นเอเจนต์เป็นผู้อ่านจึงไม่กระทบพฤติกรรม
  แต่ยินดีรับการแปลอย่างยิ่ง

## กิตติกรรมประกาศ

กฎ สคริปต์ และการตรวจประจำใน `reference/anti-self-deception/`
เป็นผลงานของ [@Karas-cnk](https://github.com/Karas-cnk) นำมารวมโดยได้รับอนุญาต `guard_the_guards.py`
และกฎเรื่องไปป์/รหัสออก ถอดแบบมาจากที่นั่น
